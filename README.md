# Loom - 2026 VGD

Link to game: https://loom-team.itch.io/loom

Loom is a metroidvania game produced for the Technology Students Association 2025-2026 Video Game Design contest. All assets are the original work of our team. The game was produced on Godot, and Aseprite was used for the pixel art.

The loom-(4.5) folder contains the assets for the version of Loom produced before the Godot 4.6 version update, and may not be up-to-date. The loom folder contains all the assets used for the most recent version of Loom, with the file organization reflecting early development. Files with the:
* .gd extension are script files
* .tres extension are resource files
* .tscn extension are scenes in Godot

P.S.: There are a lot of references to Thread, which actually means Needle. The name was retained from earlier in development.
